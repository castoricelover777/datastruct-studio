修 02-02 两个 typedef 场景的 NaN 坐标：引出线和标注一直画在画面外

render.js 从来没导出 NODE_Y / NODE_H / MID_Y，而 02-02-singly.js、02-02-doubly.js
写的是 `const { NODE_Y, NODE_H } = require('../../tools/anim/render')` ——
解构 undefined 不抛异常，于是：

  02-02-singly.js:13   const MID = (TOP + BOT) / 2;   → NaN
  02-02-doubly.js:7    const MID = NODE_Y + NODE_H / 2; → NaN

这两个文件里 17 处引用 MID 的坐标全部变成 NaN：5 条引出线画到画面外、
12 条标注（数据域 / 指针域 / 前驱 prior / 后继 next 等）全部错位。
verify.js 的 "SVG 里出现 NaN" 是唯一能扫出它的检查，所以 10550 项里就挂着这 2 条失败。

- render.js：导出 NODE_Y / NODE_H / MID_Y，并注明为什么必须导出
- 两个场景文件：改用 render 导出的 MID_Y，删掉各自算一半的写法

修完 MID = 119（结点竖直中心）：引出线 (344,121)→(446,119)、
(428,119)→(432,119) 等全部落回结点边界；两个 SVG 的 NaN 清零。
