主程序怎么用
------------

双击 exe 就行，不用装任何东西、不用配环境。
第一次打开会自己解压，可能要等几秒。

左边是目录树：章 → 节 → 模块。点一个模块，右边出代码。
工具栏上那几组按钮：

  详细注释 / 精简注释 / 无注释     同一个模块的三种注释密度
  C / Python                       同一件事的两种语言写法
  阅读模式 / 练习模式              练习模式是默写 + 编译
  深色 / 浅色                      切换主题

这一版新加了什么
----------------

Python 版：全部 26 个小节、188 个模块都有了对应的 Python 代码。
工具栏上 [C] [Python] 那组按钮切着看，注释档位、行号、语法高亮都会跟着切。

为什么值得看两种语言：同一套算法换个语言，会暴露出三件事 ——

  · C 要 malloc / free / 传二级指针改指针本身，Python 里对象就是引用，
    没这两样东西，代码短一截
  · C 的 for (j = length; j >= i; j--) 到 Python 变成 range(length, i-1, -1)，
    那个"不包含右端点"和第三个参数 -1 是初学最容易漏的
  · C 的 int 溢出会回绕、char 可能是有符号的，Python 的整数是无限精度 ——
    散列那几节这个差别特别明显，代码里专门写了怎么处理
