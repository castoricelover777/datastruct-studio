# 数据结构研习社 · 一页纸使用说明

## 启动

双击 `DataStruct-Studio-2.0.0-portable.exe` 即可，**不需要安装，也不需要装编译器**
（软件内置了 TCC；如果系统里有 gcc，会自动优先用 gcc）。

第一次启动约 0.2 秒，不联网也能完整使用。

---

## 界面三块

```
┌────────────┬──────────────────────────────────────────────┐
│  章节树    │  动画演示        │        代码                │
│  章 → 节   │  （跟着播放条走）│  （动画走到哪，这行就亮）  │
│   → 模块   ├──────────────────────────────────────────────┤
│            │  ▶ ⏮ ⏭  3.6s/8.4s  4/6 s = creatNode(e);     │
│  搜索框    │  ●━━━━●━━━━━━━━●━━━━━━●━━━━●━━━━━━●          │
│            ├──────────────────────────────────────────────┤
│  通过 0/55 │  输出面板：编译结果 / 程序输出 / 对比结果     │
└────────────┴──────────────────────────────────────────────┘
```

左侧是**章 → 节 → 模块**三层。章可以折叠，展开状态会记住；顶部搜索框输入
`applist`、`AVL`、`BFS` 能直接定位。每个模块右边有个小圆圈表示状态：

| 标记 | 含义 |
| --- | --- |
| 空心圆 | 还没练过 |
| 半黄圆 | 有草稿（默写中） |
| 实心绿圆 | 与官方实现对比**完全一致**（已通过） |

---

## 两种模式

**阅读模式**：左边看动画，右边看代码。动画每一步都会把对应的源码行高亮出来；
反过来，点代码里的某一行，动画会跳到那一步。

**练习模式**：左边默写，右边是官方实现。编辑器已经给出「已给出」的部分，
你只要写「轮到你了」下面那段。

---

## 三个按钮的用法

| 按钮 | 作用 |
| --- | --- |
| **运行**（`Ctrl + Enter`） | 真编译真运行。`gcc` 和内置 TCC 都可以 |
| **⇄ 对比** | 逐行 diff：`-` 漏写、`+` 多写、`~` 写法不同。**全对就记为「已通过」** |
| **补全脚手架** | 写乱了想重来，一键恢复到初始状态 |

编辑器下方有「**输入**」tab —— 如果程序要读键盘输入（`scanf`），把数据填在那里。

## 动画播放条

| 操作 | 怎么做 |
| --- | --- |
| 播放 / 暂停 | 点 ▶ ，或按 **空格** |
| **拖到任意时刻** | 按住进度条上的圆点拖动，画面**实时跟随** |
| 变速 | 0.5x / 1.0x / 1.5x / 2.0x，切换立即生效 |
| **单步** | 点「单步」，之后每点一次 ⏭ 前进一个关键帧 |
| 跳到某个关键步骤 | 进度条上的**小圆点**就是关键帧，鼠标悬停显示这一步的名字（如 `s = creatNode(e);`），点它直接跳过去 |
| 循环 | 「循环」按钮，开启后自动重播 |
| 快进 / 快退 | **←** / **→** |
| 上一步 / 下一步 | **,** / **.** |

> 快捷键只在有动画的模块上生效。没有动画时，**←** **→** 用来切换模块。

## 其它

- **切换注释档位**：详细注释 / 精简注释 / 无注释。三档的**代码部分完全一样**，
  只是注释多少不同 —— 默写前建议先切到「无注释」看骨架。
- **主题**：设置里可选浅色 / 深色，只影响界面，动画和代码始终是浅色底。
- **侧栏**：按 `Ctrl + B` 折叠，小屏幕上很有用。
- **模块覆盖清单**：左下角按钮，对照课程大纲看哪些节已完成、哪些还在规划。
- **草稿存在本地**（`%APPDATA%\DataStruct Studio\drafts.json`），关掉软件也不会丢。

## 卡住了怎么办

| 现象 | 原因与办法 |
| --- | --- |
| 运行报「未声明的函数」 | 那个函数属于**另一个模块**，先把它补全（脚手架里会说明依赖谁） |
| 运行时一直转圈直到超时 | 多半是死循环，检查 `p = p->next` 这类"忘了推进"的语句 |
| 对比结果是空的 | 确认「轮到你了」下面写了代码；完全是空的会提示先写 |
| 状态栏显示「没有可用的 C 编译器」 | 内置 TCC 缺失（一般不会）。重新下载一次便携版即可 |
