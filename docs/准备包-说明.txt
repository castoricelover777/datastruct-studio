怎么演示 rag.js
---------------

双击 rag-提问.cmd，然后输入问题。例如：

    二叉树的四种遍历
    队列的初始化
    图的深度优先遍历

想接 DeepSeek 生成回答，先在 PowerShell 里设环境变量：

    $env:DEEPSEEK_API_KEY="sk-你的key"

没设 key 也能跑——会自动降级成「只检索、不生成」。
上面那三条命中就是 RAG 的 R，生成是 G。


汇报时一定要主动说的两件事
--------------------------

1. 代码书写用了 AI 辅助。我自己做的是：想清楚要做什么、定下什么算做完、

2. rag.js 是 RAG，不是 Agent。主动划清界限，别夸大。


四条禁忌
--------

1. 不装熟 —— 不说「我的强项是…」，说「我遇到一个问题」「我踩了个坑」
2. 不规避 AI 辅助（主动说 + 举细节 = 可信；被问出来 = 崩）
3. 不说「我还没做完」（已完成 MVP，说「下一步是 X」）
4. 不把 rag.js 吹成 Agent
