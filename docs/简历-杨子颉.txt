## 项目经历

### 数据结构研习社 —— 学习工具的产品设计与验收
2026.09 至今　｜　独立主持（代码由 AI 编写，本人负责产品定义与验收）

项目定位：一个把数据结构教材代码拆成小块、可逐块学习与默写的桌面工具。
已发布 3 个版本（v2.0 → v2.1.3），我负责从需求到验收的全过程。

产品设计（我做的工作）：
- 定下"整章内容切成独立模块"的产品形态：单链表切成 12 块、双链表 14 块，
  每块带一句话作用、难度、依赖关系，解决"300 行一起看会懵"的问题
- 提出三档注释（详细 / 精简 / 无注释）的硬要求：切到无注释时，函数名、变量名、
  缩进必须完全不变，否则不能拿来默写
- 提出动画的交互要求：进度条可拖、可变速、可单步、可循环。理由是自己使用时发现
  "只能从头播的动画等于没有"，思考速度必须由使用者决定
- 提出默写模式：一开始完全空白，写完能编译、错在哪标出来，右边可展开参考答案
- 追加 C / Python 双语言切换：同一模块可对照两种写法，未完成的模块按钮置灰并说明原因

验收与质量控制（我做的工作）：
- 逐节实机试用，把卡手的地方记下来提改进要求
- 定下"三档注释逐字节一致""C 与 Python 输出逐字节一致"的验收口径
- 建立自动检查：格式与语法校验、字段一致性校验、覆盖率校验、
  两种语言运行输出比对、打包产物校验，共 10738 项检查
- 发现并推动修正的问题：教程中一处分栈代码写错（导致中缀转后缀结果不对）、
  解析器只判断文件首行导致的漏解析、检索工具漏载整节模块等

项目成果：
- 覆盖 6 章 25 节，214 个模块，188 段动画，配套 C 与 Python 双版本代码
- 打包为免安装单文件程序（96.3 MB），可离线运行
- 通过全部自动检查，两种语言运行结果完全一致

### 专业知识图谱与学习框架

- 把软件工程专业的全部知识范围整理成六个分支：编程与算法、系统基础、

### 检索工具（KMP 模式匹配的实际应用）
2026.09　｜　独立完成需求设计（代码由 AI 编写）

- 需求来源：让工具能自己从 214 个模块里找答案，再交给大模型按资料回答并注明来源
- 检索分两层：先用倒排索引快速圈出候选，再用 KMP 在候选里统计每个查询词的
  真实出现次数，区分"只是提了一嘴"和"整段都在讲它"
- 主导调优并定位问题：切词粒度（单字改成相邻二字）、查询词权重（按词长加权、
  把节标题纳入比对）、模块清单读取来源错误导致整节模块缺失
- 优化后典型查询命中准确：查"快速排序"直接命中对应节，查"双向链表反向打印"
  命中对应模块
