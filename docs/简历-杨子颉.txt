### 数据结构研习社 —— 学习工具的产品设计与验收
2026.09 至今　｜　独立主持

把数据结构教材代码拆成可逐块学习与默写的小块，做成免安装的桌面工具。

产品设计（我做的）：
- 定下"整章切成独立模块"的产品形态，每块标注作用、难度与依赖
- 提出三档注释的要求：切到无注释时代码本身必须完全不变，否则不能拿来默写
- 提出动画要能拖进度、变速、单步、循环——只能从头播的动画等于没有
- 提出默写模式与 C / Python 双语言对照

验收与质量控制（我做的）：
- 逐节实机试用，记录卡手的地方并提改进要求
- 建立 10738 项自动检查，其中包含"两种语言运行结果必须完全一致"这类口径
- 推动修正了教程中一处代码错误（导致运算结果不对）、检索工具漏载整节内容等问题

项目规模：25 个知识节、214 个模块，配套 C 与 Python 双版本代码。
