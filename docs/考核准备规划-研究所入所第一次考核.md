你有 **10738 条断言，一条命令跑完，0 失败**。这说明三件事：你知道"能跑"≠"对"；你有把"我觉得对"变成"机器证明对"的意识；**这个项目改得动**——有质量门兜底，才敢继续迭代。

**讲法（背下来）**：

> "我这个项目有个特点：**我改任何东西，都有一条命令告诉我有没有改坏。** 10738 条检查，覆盖 JSON 完整性、三档注释的代码是否逐字节一致、动画关键帧能不能首尾衔接、颜色字号是否统一、发版产物哈希对不对。**我之所以敢连着发 6 个版本，就是因为有这个门。**"

### 2.6 AI 辅助：主动说，别等问

**必须如实说。** 糊弄不过去，而且"不诚实"在研究所考核里是**一票否决级**的问题。

**主动坦白 + 立刻举一个只有你知道的细节 = 可信；被问出来 = 崩。**

> "这个项目的代码书写我用了 AI 辅助。我负责**需求定义、架构设计、验收标准、和全部的缺陷定位**。
>
> 我举一个只有我知道的例子：SMIL 动画里 `keyTimes` 的**最后一项必须正好等于 1**，写成 0.9999，浏览器会**静默丢弃整条动画**——不报错、不警告，就是不动，而且 DOM 里标签还在，看代码完全看不出问题。这个我排了一整晚，最后靠无头浏览器逐帧截图对比可见元素才定位到。
>
> **AI 不知道这个坑，它写出来的每一版都踩。是我定的检查项把它挡住的。**"

**这段话展示的是判断力和执行力，恰好就是考核要的两样。**

### 3.3 代码骨架（约 80 行）

```python
# rag.py —— 极小 RAG 演示：检索用倒排索引，生成用 DeepSeek
import json, os, re, urllib.request
from pathlib import Path

# ---------- ① 加载知识库：项目里已生成好的 JSON ----------
def load_chunks():
    chunks = []
    for f in Path("data").glob("*.json"):
        data = json.loads(f.read_text(encoding="utf-8"))
        for mod in data.get("modules", []):          # 按你的实际字段结构调整
            text = f"{mod.get('title','')} {mod.get('code','')} {mod.get('note','')}"
            chunks.append({"id": mod.get("id"), "text": text})
    return chunks

# ---------- ② 建倒排索引（"数据结构"真正派上用场的地方）----------
def tokenize(s):
    return set(re.findall(r"[a-zA-Z_]+|[\u4e00-\u9fa5]", s.lower()))

def build_index(chunks):
    index = {}
    for i, c in enumerate(chunks):
        for tok in tokenize(c["text"]):
            index.setdefault(tok, set()).add(i)      # 倒排表：词 -> 模块下标集合
    return index

def retrieve(query, chunks, index, k=3):
    q = tokenize(query)
    score = {}
    for tok in q:
        for i in index.get(tok, ()):
            score[i] = score.get(i, 0) + 1
    return [(chunks[i], s) for i, s in
            sorted(score.items(), key=lambda kv: -kv[1])[:k]]

# ---------- ③ 生成：调 DeepSeek ----------
def generate(query, hits):
    if not os.environ.get("DEEPSEEK_API_KEY"):
        return "（未设置 DEEPSEEK_API_KEY，跳过生成，仅显示检索结果）"
    ctx = "\n\n".join(f"【{c['id']}】\n{c['text'][:800]}" for c, _ in hits)
    prompt = (f"你是数据结构助教。只根据下面资料回答，并注明引用了哪个模块编号。"
              f"资料没有的就说不知道。\n\n资料：\n{ctx}\n\n问题：{query}")
    req = urllib.request.Request(
        "https://api.deepseek.com/chat/completions",
        data=json.dumps({"model": "deepseek-chat",
                         "messages": [{"role": "user", "content": prompt}]}).encode(),
        headers={"Content-Type": "application/json",
                 "Authorization": "Bearer " + os.environ["DEEPSEEK_API_KEY"]})
    with urllib.request.urlopen(req, timeout=60) as r:
        return json.loads(r.read())["choices"][0]["message"]["content"]

# ---------- ④ 串起来 ----------
if __name__ == "__main__":
    chunks, index = load_chunks(), None
    index = build_index(chunks)
    q = input("问点什么：")
    hits = retrieve(q, chunks, index)
    for c, s in hits:
        print(f"  · {c['id']}  （相关度 {s}）")
    print(generate(q, hits))
```

### 3.4 三个必须注意的点（**面试可能正好问这些**）

1. **API key 绝不写进代码**。用环境变量 `$env:DEEPSEEK_API_KEY="sk-..."`。
   可主动说："**我把 key 放在环境变量里，不进仓库——这是我做项目时养成的习惯。**"
2. **一定要有降级**：没网/没 key 时只跑检索、打印命中模块，**不崩**（上面的代码已处理）。
3. **别声称它是 Agent**。它是 **RAG**，是固定管线。**主动划清界限**：
   > "它是一次检索 + 一次生成，是**固定管线**。Agent 需要能在循环里自主决定调什么工具、并根据结果调整路径。**我不想把它说成 Agent 来夸大。**"

   —— **主动划界比吹成 Agent 加分得多。**
