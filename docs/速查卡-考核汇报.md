## 一、30 秒自我介绍（背下来）

> "我做了一个面向陈越《数据结构》的学习平台。它解决一个很具体的痛点：**看懂代码 ≠ 写得出来**。所以我把每个模块拆成一条闭环——分模块读、切三档注释裸看、空白默写、编译验证、跟官方实现逐行对照。现在覆盖 **25 节 214 个模块**，有 **188 段自动生成的演示动画**，交付了 **Windows 便携版**和**在线版**两个形态，并且有 **10738 条自动化检查**守着质量。"

## 三、学习过程三个故事（命中"学习过程"评分维度）

**① 主动扩大范围**
> "9/12 立项时我只做链表。做完发现**只覆盖一章的学习工具没有意义**，所以 9/14 把它重构成了覆盖全课程的平台。"

**② 高强度迭代**
> "v2.1 那几个版本是**一天之内推完的**——9/15 那天 43 次提交，修了 8 处动画缺陷，还新增了审计工具。"

**③ 敢加也敢删**（分量最重）
> "9 月 16 日我加了第 07 章，做了 7 个模块 6 段动画。**然后我自己把它删了，回退到 v2.1.3。**"
> "因为那批动画质量不达标，关键帧接不上，播起来会跳。我可以让它'看起来能跑'，但那就是在**给一个学习工具塞错的东西**。所以我用 git 回退，把那个版本和它的 Release、tag 全部删掉了。**我宁可少一章，也不要一章错的。**"

## 四、四层架构（指着图讲）

```
resources/*.c + *.h     单一真源，唯一手写维护
        ↓ build-data.js
data/*.json             模块 · 三档注释 · 元数据
        ↓ make-animations.js
docs/animations/*.svg   188 段 SMIL 动画，纯计算生成
        ↓ build-web.js
docs/ → 在线版     electron-builder → 便携 exe

verify.js → 10738 条检查，贯穿全程的质量门
```

**关键一句**：
> "**如果我不把 C 文件当唯一真相，那我改一次代码就得手动改文档、改动画、改网站，三处一定会不一致。所以我让它全部自动生成——我只维护 C 文件这一份。**"

## 五、主动要说的两件事

**① AI 辅助**（主动说，别等问）

> "这个项目的代码书写我用了 AI 辅助。我负责的是**需求定义、架构设计、验收标准、和全部的缺陷定位**。我举一个只有我知道的例子：SMIL 动画里 `keyTimes` 的**最后一项必须正好等于 1**，写成 0.9999，浏览器会**静默丢弃整条动画**——不报错、不警告，就是不动，而且 DOM 里标签还在，看代码完全看不出问题。这个我排了一整晚，最后靠无头浏览器逐帧截图对比可见元素才定位到。**AI 不知道这个坑，它写出来的每一版都踩。是我定的检查项把它挡住的。**"

**② RAG 不是 Agent**（主动划界限）

> "我写了 `rag.js`，但它**不是 Agent，是 RAG**，是一条固定管线：一次检索、一次生成。Agent 需要能在循环里自主决定调什么工具、并根据结果调整路径。**我不想把它说成 Agent 来夸大。**"

## 六、六个最高频的问题

| 问题 | 答案骨架 |
| --- | --- |
| **你对什么方向感兴趣？** | Agent 开发和软件开发，网络与信息安全也能接受。**这个项目让我看清兴趣的落点——见下条。** |
| **为什么是 Agent？** | 画完六分支我发现：③④我有实践，②是大二要补的地基，⑤是我最想去的。**而 Agent 的门槛是"会写代码 + 会调 API + 会设计循环"，这三样我都有。** 所以我没有去做玩具 Agent，而是**先把知识库建扎实**——因为 Agent 的上限取决于它能拿到什么上下文。 |
| **数据结构用到了吗？** | 代码内容是数据结构，但**工具链本身没用到复杂算法，这是我要承认的**。不过做检索时就用到了——**我在 `rag.js` 里用倒排索引实现了检索**。 |
| **最大的困难是什么？** | 最难的不是写代码，是**判断 AI 写的东西对不对**。我的办法是建自动化检查，**把"我觉得对"变成"10738 条断言全过"**。 |
| **最大的不足？** | **系统基础和数学基础薄**。我会写代码、能做工程，但操作系统、计算机网络、数据库这些地基还没打。**这是我大二要补的重点。** |
| **如果给你更多时间？** | ① 把 `rag.js` 补成完整 RAG，接进桌面版做内置问答；② 接 **GitHub Actions**，让 10738 条检查在每次提交自动跑；③ 补**可访问性**——键盘操作和屏幕阅读器，**188 段动画对看不见的人目前完全不可用，这一点我做得不够**。 |
