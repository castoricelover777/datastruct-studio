**大一新生，开学第二周。9 月 12 号——开学第五天——我开始做这个项目。**

## 一、30 秒开场（背下来）

> "我是**大一新生，开学第二周**。
>
> 我自学陈越《数据结构》的时候卡住过——**看视频能看懂，合上书自己写链表的指针就写不出来**。
>
> 所以我做了一个工具逼自己写：每个模块分成五步——分块读、切三档注释裸看、空白默写、编译验证、跟教材对照。现在覆盖 **25 节 214 个模块**，有 **188 段动画**，做成了 Windows 便携版和在线版。
>
> **代码书写我用了 AI 辅助，我负责定需求、定验收标准、和找 bug。**"

**这段里有：身份 → 我的真实痛点 → 方案 → 规模 → 诚实的边界。**
**最后那句一定要主动说，别等人问。**

## 三、学习过程三个故事（**命中考评分第一维度**）

**① 开学第五天就动手**
> "开学第一周我还在适应，**第二周我就想找点事做。**"

**② 主动扩大范围**
> "我一开始只做链表。做完发现**只覆盖一章的学习工具没什么用**，所以又花了几天重做成覆盖全课程的平台。"

**③ 敢加也敢删**（分量最重）
> "9 月 16 号我加了第 07 章，做了 7 个模块 6 段动画。**然后我自己把它删了，退回上一个版本。**
> 因为那批动画质量不行——关键帧接不上，播起来会跳。我也可以让它'看起来能跑'，但那是**给一个学习工具塞错的东西**。
> 所以我用 git 退回去了，把那个版本和发的包都删掉了。**我宁可少一章，也不要一章错的。**"

## 四、我的文件是怎么走的（指着图讲，别说"架构"）

```
C 源文件（我只维护这一份）
   ↓ build-data.js
data/*.json（模块 · 三档注释）
   ↓ make-animations.js
188 段 SVG 动画
   ↓ build-web.js
在线版 + 便携 exe

verify.js → 10738 条检查
```

**关键一句（注意说法）**：
> "**一开始不是这样。**我改一次代码要改三个地方，改漏了好几次。**后来我才改成从 C 文件自动生成。**"

> ⚠️ 不要说"这是我的关键设计决策"或"我设计了单一真源架构"——**说"我踩了个坑，后来改了做法"**。

## 五、主动要说的两件事

**① AI 辅助**（主动说，别等问）

> "**代码书写我用了 AI 辅助。**我自己做的是：**想清楚要做什么、定下什么算做完、找出哪里不对。**
>
> 举个只有我知道的例子：SMIL 动画里 `keyTimes` 的**最后一项必须正好等于 1**，写成 0.9999，浏览器会**静默丢弃整条动画**——不报错、不警告，就是不动，而且标签还在页面里，看代码完全看不出来。这个我排了一整晚，最后靠无头浏览器逐帧截图对比才找到。
> **AI 不知道这个坑，它写的每一版都踩。是我加的检查把它挡住的。**"

**② RAG 不是 Agent**（主动划界限）

> "我写了 `rag.js`，但它**不是 Agent，是 RAG**——一条固定管线：一次检索、一次生成。Agent 需要自己决定调什么工具、根据结果换路线。**Agent 我还没动手做过，不想把它说成 Agent 来夸大。**"

## 六、七个必背问题

| 问题 | 答案骨架 |
| --- | --- |
| **你大几？学过什么？** | **大一，开学第二周。** C 是暑假自学，数据结构是我提前在学。**专业课大部分还没上到**——操作系统、网络、数据库都在大二。 |
| **为什么选数据结构？** | 因为我学它**真的卡住过**。选自己卡住的地方做项目，动力最足。 |
| **你对什么方向感兴趣？** | Agent 开发和软件开发，网络与信息安全也能接受。**这个项目让我看清了兴趣的落点。** |
| **为什么是 Agent？** | 数学和深度学习我现在啃不动，**但 Agent 的门槛是"会写代码 + 会调 API + 会设计循环"，这三样我刚好都在够得着的地方**。所以我没有先做玩具 Agent，而是**先把我能建的知识库建扎实**——我看到一个说法：Agent 的上限取决于它能拿到什么上下文。 |
| **数据结构用到了吗？** | **写代码时没怎么用到算法，这点我得承认。** 但写 `rag.js` 时用到了——**检索用的是倒排索引**。 |
| **最大的困难？** | **最难的不是写代码，是我看不懂它写得对不对。** 我吃过一次亏之后，就把能自动检查的都写成了检查。 |
| **最大的不足？** | **专业课我才刚开始上。** 计组、操作系统、网络、数据库**这四门都没学过**。另外写代码我还不行——**看得懂，但离开参考自己从零写还写不出来**，这也是我做这个项目的原因。 |

> ⚠️ **"最大的不足"这题千万别说"系统基础薄"**——那不叫不足，那叫"还没学到"，是大一最正常的状态。
> 说出来，并且说出"我知道它们在大二"——**"我知道自己缺什么、也知道什么时候补"，比装什么都会强。**

## 八、四条禁忌

1. **不装熟** —— 不说"我的强项是…""我设计了…"。**说"我遇到一个问题""我踩了个坑"**
